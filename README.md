# codigo-claude-introduccion

Código y recursos del curso **Introducción a Claude** para principiantes.

## Sobre el curso

Curso pensado para quienes empiezan desde cero con Claude. Aquí encontrarás el material que se usa en las clases prácticas (demos), organizado por secciones a medida que avanza el curso.

## Estructura

Cada carpeta se organiza por sección del curso y, dentro, por práctica:

- `0-Materiales/<Sección>/<Práctica>/`: archivos que usarás en la práctica.
- `1-Enunciados/<Sección>/Enunciado - <Práctica>.pdf`: los pasos y prompts de cada práctica.
- `2-Resultados/<Sección>/<Práctica>/`: lo que devolvió Claude en la grabación, para comparar.

## Cómo usar este repositorio

1. Clona el repositorio o descárgalo como ZIP desde el botón **Code**.
2. Abre la carpeta de la sección que estés viendo en el curso y busca la práctica por su nombre.
3. Sigue la clase en vídeo y usa los archivos como punto de partida.

```bash
git clone https://github.com/joaneeet7/codigo-claude-introduccion.git
```

## Requisitos

- Una cuenta de Claude ([claude.ai](https://claude.ai))
- Ganas de aprender, no hace falta experiencia previa
